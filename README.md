# Mouse-Motion-Automator
# 🖱️ Mouse Path Automator Pro (MPA Pro)

**Mouse Path Automator Pro** — это продвинутый инструмент для автоматизации действий мыши. В отличие от стандартных автокликеров, MPA Pro умеет перемещать курсор по сложным траекториям, имитируя реальные движения человека или следуя строгим геометрическим формам.

---

## 🔥 Ключевые возможности

*   **📐 Геометрические траектории:** Движение по идеальному кругу, квадрату, зигзагу или бесконечности (восьмерке).
*   **📏 Линейные режимы:** Горизонтальные и вертикальные линии для точных задач.
*   **🎙️ Запись движений (Record & Playback):** Запишите любой произвольный путь мыши, и программа будет повторять его бесконечно.
*   **🤖 Анти-бот система (Human Noise):** Функция рандомизации добавляет микро-дрожание к движениям, делая их похожими на человеческие.
*   **📍 Гибкий центр:** Возможность задать центр вращения в любой точке экрана (или под курсором).
*   **💾 Умная память:** Программа автоматически сохраняет все ваши настройки (скорость, радиус, клавиши) в файл `settings.json`.
*   **⌨️ Глобальные хоткеи:** Управляйте стартом и стопом (F9/F10 по умолчанию) даже когда приложение свернуто.
*   **📥 Работа в фоне:** Сворачивается в системный трей и не мешает основной работе.

---

## 🛠 Настройки

1.  **Форма:** Выберите одну из 7 доступных траекторий.
2.  **Радиус:** Настройте масштаб движения (от 50 до 500 пикселей).
3.  **Скорость:** Плавная регулировка скорости перемещения курсора.
4.  **Кнопка:** Выберите, какую кнопку мыши зажимать (ЛКМ, ПКМ или СКМ).
5.  **Циклы:** Выставьте лимит кругов или оставьте бесконечный режим.

---

## 🚀 Как запустить

1. Перейдите в раздел **[Releases](../../releases)** на этом GitHub.
2. Скачайте файл `MouseSimulator.exe`.
3. Запустите его (рекомендуется **от имени Администратора**, чтобы горячие клавиши работали поверх всех окон).

> **💡 Совет:** Чтобы мгновенно остановить скрипт в любой момент, просто резко дерните мышь в любой угол монитора (сработает аварийный Fail-Safe).

*   `pyautogui` — управление мышью.
*   `tkinter` — графический интерфейс.
*   `keyboard` — глобальное отслеживание клавиш.
*   `pystray` — работа с системным треем.
